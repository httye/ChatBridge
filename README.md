## ⚙️🔧 配置说明 🔧⚙️

### 📝📋 完整配置示例

```yaml
# 服务器配置 🏠
server:
  name: "Server1"         # 服务器唯一标识 🔑
  display-name: "&a&l生存服"  # 服务器显示名称（支持颜色代码）🎨
  prefix:
    enabled: true         # 是否显示服务器前缀 ✅
    format: "&7[&b{server}&7]"  # 服务器前缀格式 🏷️
    position: "before_name"     # 前缀位置 📍

# 聊天配置 💬
chat:
  enabled: true           # 是否启用聊天同步 ✅
  sync-server-status: true # 是否同步服务器状态 📢

# 敏感词过滤已内置并启用 🚫
```

### 🏷️🎨 服务器前缀配置

**配置项说明：**

| 配置项 | 说明 | 说明 |
|--------|------|------|
| `enabled` | 是否启用服务器前缀 | ✅/❌ |
| `format` | 前缀格式，`{server}` 会替换为服务器显示名称 | 🏷️ |
| `position` | 前缀位置 | 📍 |

**位置效果：**

| 位置选项 | 效果 |
|----------|------|
| `before_name` | 🏷️ `[生存服] 玩家名: 消息内容` |
| `before_message` | 🎨 `玩家名: [生存服] 消息内容` |

**配置示例：**

```yaml
server:
  display-name: "&a&l生存服"
  prefix:
    enabled: true
    format: "&7[&b{server}&7]"
    position: "before_name"
```

**消息格式：**
- 💬 聊天：`🌟[生存服] 玩家名: 消息内容`
- 👋 加入：`🎉[生存服] 玩家 加入了游戏`
- 👋 退出：`👋[生存服] 玩家 离开了游戏`
- 📢 启动：`🚀[生存服] 服务器已启动`
- 🔕 关闭：`😴[生存服] 服务器已关闭`

## 🌐🏰 多服务器部署（让你的服务器大家庭壮大起来！🎊） 🏰🌐

### 🎯📋 部署步骤（一步步来，很简单哒~）

1. 📥 在每个服务器上安装此插件，一个都不能少！ 📥
2. 🔑 为每个服务器配置唯一的 `server.name`，要不一样哦！ 🔑
3. 🎨 配置各服务器的 `server.display-name`，取个好听的名字~ 🎨
4. 🔗 确保所有服务器连接到同一个 Redis 实例，这样才能互相聊天！ 🔗

### 📌🏷️ 配置示例（参考一下，改改就好~）

**服务器 1 - 生存服 🌳🏡**
```yaml
server:
  name: "survival"
  display-name: "&a&l🌳生存服"
```

**服务器 2 - 创造服 🎨🎭**
```yaml
server:
  name: "creative"
  display-name: "&b&l🎨创造服"
```

**服务器 3 - 小游戏服 🎮🎲**
```yaml
server:
  name: "minigames"
  display-name: "&e&l🎮小游戏服"
```

**小贴士💡：** 服务器名称要独一无二，就像每个人的名字一样特别！

## ❓💡 常见问题（遇到问题不要慌，看这里！👀） 💡❓

### 🤔🤷‍♂️ 消息没有同步到其他服务器？（别急，检查一下~）

请检查这些地方：
1. ✅ Redis 服务是否正常运行？是不是忘启动了？ 🔴
2. 🔗 所有服务器是不是连接到同一个 Redis 实例？连接对了吗？ 🔗
3. 📊 用 `/chatbridge status` 检查连接状态，看看报什么错 📊
4. 🔑 确认服务器密钥是不是正确配置，密码输对了吗？ 🔑

### 🎭👑 玩家前缀/后缀不显示？（看起来不太对劲？）

要安装 LuckPerms 或 Vault 插件哦，并正确配置了权限组的前缀/后缀~ 没配置的话当然不显示啦！ 👑

### 🚫🔇 如何禁用某些消息同步？（不想要某些功能？）

在 `config.yml` 里改成 `false` 就可以啦：
- `chat.enabled` - 关掉聊天同步，不想聊天就关掉 💬
- `chat.sync-server-status` - 关掉服务器状态同步，不想看到通知 📢

### 🏷️🎨 如何自定义服务器前缀显示？（想要个性化？）

在 `server.prefix` 配置里：
- 设置 `enabled: true/false` 决定要不要显示 ✅
- 设置 `format` 自定义前缀格式，用 `{server}` 代表服务器名称 🏷️
- 设置 `position` 控制前缀位置，放在前面还是后面~ 📍
